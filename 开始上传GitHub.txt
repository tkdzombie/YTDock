YTDock 1.2 — GitHub 更新与发布

如果你的本地仓库仍在 /Users/lazydog/Downloads/YTDock：

1. 使用 1.2 UpdateKit 的 update.sh 更新源码。
2. update.sh 会保留原仓库的 .git 和 GitHub remote。
3. 确认 VERSION = 1.2.0。
4. 选择提交并 push main。
5. 选择发布 v1.2.0。
6. GitHub Actions 会构建：
   YTDock-1.2.0-arm64.dmg
   YTDock-1.2.0-x86_64.dmg
7. 构建成功后两个 DMG、SHA256SUMS.txt 和 BUILDINFO 会进入同一个 GitHub Release。

注意：免费构建是 ad-hoc 签名，不是 Developer ID 签名，也没有 Apple notarization。
