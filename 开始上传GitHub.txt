YTDock 1.1 — GitHub 发布说明

如果你已经有 https://github.com/tkdzombie/YTDock：

1. 把 1.1.0 的改动更新到你的本地仓库。
2. 确认 VERSION 是 1.1.0。
3. git add / commit / push 到 main。
4. 双击 publish.command，或在 Terminal 执行：

   ./publish.command

5. 脚本会创建 v1.1.0 tag。
6. GitHub Actions 会分别构建：

   YTDock-1.1.0-arm64.dmg
   YTDock-1.1.0-x86_64.dmg

7. 两个架构都验证成功后，Release 会自动创建/更新。

如果这是一个全新的仓库，才需要运行 setup-github.command。

YTDock 免费发布流程不需要 Apple Developer 会员，也不会把 GitHub Token 写入项目文件。
